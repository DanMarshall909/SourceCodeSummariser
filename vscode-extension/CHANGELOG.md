# Change Log

All notable changes to the "SourceCode Summariser" extension will be documented in this file.

## [1.0.0] - 2024

### Added
- Initial release of SourceCode Summariser VSCode extension
- Workspace and file analysis commands
- AI-powered code summarization using OpenAI, Anthropic, or local LLMs
- Semantic search functionality with vector embeddings
- Tree view for browsing code summaries organized by file
- Hover provider showing AI-generated summaries on mouse hover
- Watch mode for automatic summary updates on file changes
- Context menu integration for analyzing files from explorer
- Configuration settings for LLM providers and analysis options
- Support for multiple LLM providers (OpenAI, Anthropic, Ollama)
- Auto-detection of SourceCodeSummariser tool path
- Statistics display showing total files and members analyzed
- Detailed member view with summary, file location, and tags
- Workspace initialization command
- Comprehensive documentation and troubleshooting guide

### Features
- 🤖 AI-powered code analysis for C# projects
- 🔍 Semantic code search by meaning, not keywords
- 📊 Visual tree view of all summaries
- 💡 Inline hover tooltips with summaries
- 👁️ Watch mode for real-time updates
- 🎯 Right-click context menu actions
- ⚙️ Flexible LLM provider configuration
